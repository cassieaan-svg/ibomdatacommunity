Who We Are

Building a Data-Literate Akwa Ibom

Ibom Data Community was founded on one belief: great data skills should be accessible to everyone. We connect data enthusiasts, host learning events, run mentorship programmes, and create spaces where knowledge flows freely — from beginners to seasoned professionals.

📚

Knowledge Sharing

Data for Everyone
