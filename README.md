# Ibom Data Community Website

Official website for **Ibom Data Community** — a growing network of data enthusiasts across Nigeria, connecting professionals, hosting events, and making data skills accessible to everyone in Akwa Ibom and beyond.

🌐 **Live site:** [ibomdatacommunity.com.ng](https://ibomdatacommunity.com.ng)

## Deployment

The site is hosted on **Netlify** with the custom domain `ibomdatacommunity.com.ng`.

- DNS is managed via **Go54** (nameservers pointed to Netlify)
- SSL certificate is automatically provisioned by Netlify
- To redeploy: drag the project folder onto the Netlify deploy zone at [app.netlify.com](https://app.netlify.com)
