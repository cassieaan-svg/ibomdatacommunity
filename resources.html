📚 Knowledge Resources

Learn Data Skills — For Free

Curated tools, courses, and platforms to take you from beginner to job-ready. Handpicked by the IDC team.

💡

IDC Tip: Start With One Tool

Don't try to learn everything at once. Pick one tool, commit to 30 minutes a day for 30 days, and build a small project. Then move to the next. Join our community group to share your progress and get support from fellow learners.

🟢 Beginner Resources

Beginner

Never worked with data before? Start here. These tools and courses are designed to be accessible to complete beginners — no coding experience required for most of them.

📊
Microsoft Excel
Microsoft 365 / Desktop

The cornerstone of data analysis. Learn formulas, pivot tables, charts, and VLOOKUP. Excel is the most widely used tool in business data work and an essential first step.

Free to Learn Explore →
🟩
Google Sheets
Google Workspace

A free, browser-based alternative to Excel. Great for collaboration and sharing. Learn the same core spreadsheet skills — formulas, charts, and data cleaning — with nothing to install.

100% Free Explore →
🎓
Google Data Analytics Certificate
Coursera

A structured 6-month programme covering spreadsheets, SQL, Tableau, and R. Designed for complete beginners, it's one of the most recognised entry-level data credentials available. IDC members have received this scholarship.

Audit Free / Paid Cert Explore →
🗄️
SQL for Beginners
Mode / W3Schools / SQLZoo

SQL is the language of databases and one of the most in-demand data skills globally. Start with SELECT, WHERE, GROUP BY, and JOINs. SQLZoo and W3Schools both offer free interactive exercises with instant feedback.

Free Explore →
📈
Power BI Desktop
Microsoft Power BI

A free, powerful business intelligence tool from Microsoft. Connect to data sources, build interactive dashboards, and create reports that tell stories. Widely used across Nigerian companies and globally in demand.

Free Desktop App Explore →
🎯
Khan Academy — Statistics
Khan Academy

Understanding data starts with understanding statistics. Khan Academy's free Statistics and Probability course is clear, beginner-friendly, and interactive. Learn mean, median, distributions, and probability from scratch.

100% Free Explore →

🔵 Intermediate Resources

Intermediate

Ready to go deeper? These resources build on spreadsheet and SQL foundations, introducing programming, advanced visualisation, and data storytelling.

🐍
Python for Data Analysis
Kaggle Learn / freeCodeCamp

Python's Pandas and NumPy libraries make data wrangling at scale possible. Kaggle Learn offers a free, self-paced Python for Data Science course that's practical and project-based — great once you're comfortable with SQL basics.

Free Explore →
📐
R for Data Science
r4ds.had.co.nz

The free online book "R for Data Science" by Hadley Wickham is the definitive guide to using R with the tidyverse. Excellent for statistical analysis, academic research, and producing beautiful visualisations with ggplot2.

Free Explore →
🔷
Tableau Public
Tableau

Tableau is one of the most powerful data visualisation tools available. Tableau Public is free and lets you build and publish stunning interactive dashboards. An excellent portfolio-builder and widely recognised by employers.

Free Explore →
🗃️
Advanced SQL
Mode Analytics / StrataScratch

Go beyond basic queries with window functions, CTEs, subqueries, and performance optimisation. StrataScratch has real interview-style SQL questions from top companies — excellent for job preparation and sharpening analytical SQL skills.

Free / Freemium Explore →
📖
Storytelling with Data
Book + Blog (Cole Nussbaumer Knaflic)

Data analysis is only as valuable as the story it tells. This blog (free) and book teach you how to choose the right chart, eliminate clutter, and design dashboards that drive decisions. One of the most recommended resources in the data community.

Blog Free / Book Paid Explore →
🤖
Kaggle Competitions & Notebooks
Kaggle

Kaggle is the world's largest data science community. Browse thousands of public datasets, study winning notebooks, and enter competitions to build real-world problem-solving experience. A must-have for any growing data analyst.

Free Explore →

🔴 Advanced Resources

Advanced

For practitioners ready to move into machine learning, data engineering, and specialised analytics domains.

🧠
Machine Learning — Andrew Ng
Coursera / DeepLearning.AI

The gold standard for learning machine learning. Andrew Ng's courses are clear, rigorous, and taught by one of the field's pioneers. Covers supervised learning, neural networks, and best practices for real-world ML systems.

Audit Free Explore →
⚙️
Data Engineering Zoomcamp
DataTalks.Club

A free 9-week cohort-based course covering the full data engineering stack — containerisation, data warehousing, workflow orchestration, batch and streaming processing. Industry-aligned and project-driven.

Free Explore →
📊
dbt (Data Build Tool)
dbt Labs

dbt is transforming how analytics engineering is done. Learn to build scalable data transformation pipelines in SQL, write tests, and document your data models. dbt Learn offers free courses directly from the creators.

Free Explore →
